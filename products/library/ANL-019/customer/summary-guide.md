# Billable utilisation hours

*Excel summary plus a CSV for Power BI Desktop.*

Billable hours by person. Available hours are not in the table, so utilisation is not pretended.

1. Open summary.xlsx and confirm the total matches the data sheet.
2. Load facts.csv into Power BI Desktop as a table named Facts.
3. Paste measures.dax into new measures.
4. Replace the sample rows before you use the numbers in a report.

> The workbook and CSV are sample data for learning the model. A PBIX file is not included. Paste the DAX into Power BI Desktop after you load the CSV. This is not a financial audit.
