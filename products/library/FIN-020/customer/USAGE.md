# How to use Annual money review

*Excel workbook with PDF guide*

Each month has income, costs, and a surplus formula. The review shows the total, the average, the best month, and the worst month. Next year's monthly target is something you type, and the sheet shows the gap against the average.

## Who it is for

Households doing a once-a-year review of their own records.

## Compatibility

- Microsoft Excel for Microsoft 365 or Excel 2021 and later
- Formulas also open in Google Sheets; confirm PMT, FV, and NPER after import
- PDF guide opens in any PDF reader
- DOCX guide opens in Microsoft Word or Google Docs

## Before you start

1. Read the README and this usage guide.
2. Open the main deliverable and replace every sample figure or sample sentence with your own.
3. Keep a copy of the original download before you edit it.
4. Check the licence before you share the edited file with anyone else.

## What you should see

- See which month actually carried the year
- Use your own monthly figures, not a generic average
- Set next year's target beside the evidence
