# Event budget variance

*FIN-009 · version 1.0.0*

Set a planned amount for each event cost and record what you actually pay.

Variance is actual minus plan. The workbook totals both columns and shows which lines ran over. It is built for a 40-person family celebration, and the categories can be renamed.
