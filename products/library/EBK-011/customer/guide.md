# Accessibility basics for a small site

*A practical pass over a small website: headings, contrast, forms, and keyboard use.*

## Headings and names

The page title and the first heading should say where the person is. Buttons should say what they do. 'Click here' does not. Images that carry meaning need a text alternative. Decorative images do not.

- One clear page title.
- Buttons named as actions.
- Text alternatives for meaningful images.

## Colour

Do not use colour as the only signal. A red error also needs words. Check the contrast of body text on the background. Pale grey on cream fails people, including you in sunlight.

- Errors in words.
- Body text dark enough.
- Links visible without relying on colour alone.

## Keyboard

Tab through the page. You should see where you are, reach every control, and not get trapped. A menu that only opens on hover fails this test.

- Visible focus.
- Every control reachable.
- Escape closes a dialog.

## Forms

Every field has a label that is connected to it, not only a placeholder. Errors say which field and how to fix it. Required fields are marked in text.

- Labels, not only placeholders.
- Specific errors.
- Required marked in text.
