# How to use Accessibility basics for a small site

*PDF guide with Markdown and DOCX*

A practical pass over a small website: headings, contrast, forms, and keyboard use.

## Who it is for

People shipping a small site who are not accessibility specialists.

## Compatibility

- Any PDF reader
- Microsoft Word or Google Docs for the DOCX
- A text editor for the Markdown

## Before you start

1. Read the README and this usage guide.
2. Open the main deliverable and replace every sample figure or sample sentence with your own.
3. Keep a copy of the original download before you edit it.
4. Check the licence before you share the edited file with anyone else.
