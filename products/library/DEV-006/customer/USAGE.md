# How to use Fixed-window rate limit

*JavaScript source with node:test*

An in-memory counter for one process. It is useful in tests and small Node servers. It does not share state across servers, and it forgets everything when the process stops.

## Who it is for

Developers who want a small, readable module they can drop into a Node.js project and modify.

## Compatibility

- Node.js 20 or later
- Run npm test or node --test from this folder

## Before you start
