# Study notes from a source

*These prompts draft text for you to edit. They do not check facts, quotes, or the law. Remove anything the model invented before you send it.*

## Questions

Use when: You have a chapter.

Write ten questions the chapter can answer. Do not write the answers yet.

> Check: Each question is in the chapter.

## Answers

Use when: You are ready.

Answer those questions from the chapter. If the chapter does not answer one, say so.

> Check: Missing answers are marked.

## Teach it

Use when: You need to remember.

Explain the idea as if to a classmate, using an example from the chapter. Do not import an example from another subject.

> Check: The example is from the text.

## Confusions

Use when: You are stuck.

List the terms the chapter uses that it does not define.

> Check: You look those up in the course, not in a guess.

## One-page sheet

Use when: Before a test.

Make a one-page sheet of definitions and steps from the chapter. No extra topics.

> Check: A classmate can see it is this chapter.

## Practice

Use when: You need to try.

Write five practice tasks at the same level as the chapter's examples. Mark them as practice, not as official questions.

> Check: They are labelled practice.
