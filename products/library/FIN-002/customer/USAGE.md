# How to use Debt payoff comparison

*Excel workbook with PDF guide*

See this month's interest and a months-to-clear estimate for each debt if you keep paying the current minimum. A second estimate shows the effect of putting one extra amount onto the highest-rate debt.

## Who it is for

People with two or three consumer debts who want a payment order before they call a credit provider.

## Compatibility

- Microsoft Excel for Microsoft 365 or Excel 2021 and later
- Formulas also open in Google Sheets; confirm PMT, FV, and NPER after import
- PDF guide opens in any PDF reader
- DOCX guide opens in Microsoft Word or Google Docs

## Before you start

1. Read the README and this usage guide.
2. Open the main deliverable and replace every sample figure or sample sentence with your own.
3. Keep a copy of the original download before you edit it.
4. Check the licence before you share the edited file with anyone else.

## What you should see

- See interest building this month on each balance
- Estimate months left at the current minimum
- See the shorter estimate when extra money goes to the highest rate
