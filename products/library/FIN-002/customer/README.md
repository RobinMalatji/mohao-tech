# Debt payoff comparison

*FIN-002 · version 1.0.0*

Compare minimum payments with a snowball order and an avalanche order for three debts.

See this month's interest and a months-to-clear estimate for each debt if you keep paying the current minimum. A second estimate shows the effect of putting one extra amount onto the highest-rate debt.
