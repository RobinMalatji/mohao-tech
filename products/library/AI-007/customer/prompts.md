# Requirement writing prompts

*These prompts draft text for you to edit. They do not check facts, quotes, or the law. Remove anything the model invented before you send it.*

## One sentence

Use when: The request is a paragraph.

Rewrite the request as: who, does what, so that. If the notes do not say why, write 'why not stated'.

> Check: You did not invent the why.

## Acceptance

Use when: You need a test.

Write acceptance checks a person can run without reading your mind. Use the inputs I provided.

> Check: Each check is observable.

## Out of scope

Use when: The request is growing.

List three nearby ideas that this requirement does not include.

> Check: The developer can see the boundary.

## Edge cases

Use when: Before you build.

List empty, duplicate, and permission failures for this requirement. Mark any you cannot answer as a question.

> Check: Questions are not disguised as facts.

## Plain words

Use when: The draft is jargon.

Replace jargon with the words a new teammate would use. Do not change the decision.

> Check: The decision is the same.

## Ready check

Use when: Before it goes to a developer.

Say what is still missing: data, design, copy, or a decision. Do not fill the gap yourself.

> Check: Missing items stay missing.
