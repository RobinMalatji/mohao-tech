# Choose a small tech stack

*Pick tools for a small product without collecting a platform for every job.*

## The jobs

List the jobs: page, accounts, data, payments, email, files. A tool can cover more than one. A job with no tool is a gap. A tool with no job is a subscription you will forget.

- Write the jobs.
- Write the tool for each.
- Cross out a tool with no job.

## Boring on purpose

Choose a database, a framework, and a host you can hire for. Novelty is expensive when you are the only developer. Write down what you already know how to run.

- One database.
- One host.
- A person you could hire who knows it.

## Payments and files

Do not store cards. Use a provider. Do not put private downloads in a public folder. Those two decisions cause more pain than the colour of the dashboard.

- A payment provider.
- Private file storage.
- No card numbers in your database.

## A review date

Write a date in six months to ask whether each tool earned its place. Until then, do not add another because a talk was exciting.

- Six-month review.
- No new tool without a job.
- Write the cost next to the tool.
