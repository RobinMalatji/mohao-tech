# How to use Discount calendar

*Excel workbook and PDF guide*

A year of planned discounts so a sale is a decision, not a panic.

## Who it is for

Shops that discount too often.

## Compatibility

- Word or Docs for DOCX
- Excel for workbooks
- A text editor for Markdown and CSV
