# Lesson building desk

*NOT-014 · version 1.0.0*

A desk for building one short course: outcome, lesson, exercise, and the file the learner gets.

Used to plan a fictional four-lesson course on writing a project brief. Each lesson has an exercise and a file. If there is no exercise, the lesson is not ready.
