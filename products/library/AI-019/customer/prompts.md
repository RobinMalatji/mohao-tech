# Hospitality copy prompts

*These prompts draft text for you to edit. They do not check facts, quotes, or the law. Remove anything the model invented before you send it.*

## Dish line

Use when: You have a dish.

Write a one-line description using only the ingredients and the method I list. Do not call it authentic or award-winning.

> Check: No extra claim.

## Allergen caution

Use when: You are not sure.

If I did not list allergens, write that guests must ask, rather than inventing 'allergen free'.

> Check: No allergen was invented.

## Booking confirmation

Use when: A table is booked.

Write the confirmation with the name, date, time, and party size I provide. Ask them to reply if the party size changes.

> Check: Every detail matches.

## Full

Use when: You are fully booked.

Write a reply that says full and offers the next time I provide. Do not offer a discount.

> Check: No discount.

## Specials board

Use when: Three specials.

Write the board. Include the price I set. If a special has no price, mark it missing rather than inventing one.

> Check: Prices are mine.

## Quiet description

Use when: The about text is loud.

Rewrite the about text so a neighbour would believe it. Remove claims I cannot point at.

> Check: You can defend every line.
