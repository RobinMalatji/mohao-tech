# Travel budget planner

*FIN-015 · version 1.0.0*

Build a trip cost from nights, daily food, transport, and a contingency percentage.

The sample is four nights in Cape Town for two adults travelling from Johannesburg. You can change every driver. Contingency is a percentage of the subtotal, not a guess typed at the end.
