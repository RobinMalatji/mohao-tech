# How to use Retirement contribution sketch

*Excel workbook with PDF guide*

The future value uses the rate you enter. It is an illustration, not a forecast and not a retirement-fund quote. Fees, tax, and inflation are not modelled.

## Who it is for

People who want to see how a monthly contribution and an assumed rate interact before they speak to a fund or adviser.

## Compatibility

- Microsoft Excel for Microsoft 365 or Excel 2021 and later
- Formulas also open in Google Sheets; confirm PMT, FV, and NPER after import
- PDF guide opens in any PDF reader
- DOCX guide opens in Microsoft Word or Google Docs

## Before you start

1. Read the README and this usage guide.
2. Open the main deliverable and replace every sample figure or sample sentence with your own.
3. Keep a copy of the original download before you edit it.
4. Check the licence before you share the edited file with anyone else.

## What you should see

- See the balance an assumed rate produces
- Change the rate without hiding that it is an assumption
- Keep the current savings separate from new contributions
