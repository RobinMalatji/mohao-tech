# Retirement contribution sketch

*FIN-012 · version 1.0.0*

Project a savings balance from a contribution and an assumed return you type in.

The future value uses the rate you enter. It is an illustration, not a forecast and not a retirement-fund quote. Fees, tax, and inflation are not modelled.
