# Import Reading notes desk

*This is a Markdown and CSV package you import into Notion yourself. It is not a published Notion template and it does not include a Notion share link.*

A reading system for operators, not a star rating. Each note has a claim, where it is in the book, and whether it changes a decision.

## Import into Notion

1. In Notion, choose Import, then Markdown & CSV.
2. Import the Markdown pages in the pages folder.
3. Import notes.csv and check that the column names match the header row.
4. Replace the sample rows before you rely on the board.
5. There is no Notion link in this package. If a seller sends you only a link, that is a different product.
