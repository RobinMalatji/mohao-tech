# How to use Retail supervisor CV kit

*DOCX CV, PDF guide, and Markdown*

A CV for a shop supervisor: rota, cash, and the floor. The sample person is fictional. The guide tells you which lines to replace and what evidence to keep.

## Who it is for

Supervisors applying to larger stores.

## Compatibility

- Microsoft Word or Google Docs
- Any PDF reader for the guide

## Before you start

1. Read the README and this usage guide.
2. Open the main deliverable and replace every sample figure or sample sentence with your own.
3. Keep a copy of the original download before you edit it.
4. Check the licence before you share the edited file with anyone else.

## What you should see

- A CV structure aimed at one kind of role
- Sample bullets that show evidence, which you replace
- A checklist for the send
