# How to use Password policy check

*JavaScript source with node:test*

Rejects passwords under 12 characters, passwords that are only letters, and a short list of common values. It returns the failures. It does not hash or transmit the password.

## Who it is for

Developers who want a small, readable module they can drop into a Node.js project and modify.

## Compatibility

- Node.js 20 or later
- Run npm test or node --test from this folder
