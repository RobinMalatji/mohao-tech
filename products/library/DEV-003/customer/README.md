# Currency formatter

*DEV-003 · version 1.0.0*

Format integer cents as ZAR, USD, GBP, or EUR without converting between them.

Formats an amount you already store in one currency. It refuses to invent an exchange rate. Amounts must be integer cents so 1999 is R19.99, not a float.
