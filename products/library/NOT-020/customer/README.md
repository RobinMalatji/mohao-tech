# Neighbourhood newsletter desk

*NOT-020 · version 1.0.0*

An issue plan with a writer, a word count, and a deadline before print day.

For a fictional letter, Block Notes, printed monthly. Each item has a writer and a maximum word count so the issue fits four pages.
