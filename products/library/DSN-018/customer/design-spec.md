# Cafe loyalty card

*SVG files you can upload. Not a native Canva template.*

A loyalty card for fictional Compass Coffee. Ten stamps, and the tenth coffee is the reward. The terms are one line: one stamp per visit, not per cup in the same order.

## Files and sizes

| File | Pixels |
| --- | --- |
| loyalty-card.svg | 1600 x 900 |

## How to edit

1. Change the reward if you are not giving a coffee.
2. Print on card and cut. The SVG includes ten empty circles as the stamp row in the line text.
3. Tell staff the one-stamp rule so the card matches the counter.

## Canva, Figma, and print

Create a design at the pixel size in the table, then upload the SVG. In Canva this is an upload, not a brand template from Canva's library. In Figma, place the SVG and edit the text layers. For print, add bleed in the editor. The SVG is the design area.

> Sample names and offers in these designs are fictional. Replace them before you publish. This package is not a native Canva file.
