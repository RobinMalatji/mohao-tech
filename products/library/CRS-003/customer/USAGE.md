# How to use SQL for operators

*Lessons, slides, and a worksheet*

Read a query: filters, joins, and the grain of the result. Four short lessons, a slide file, and a worksheet. Study it on your own.

## Who it is for

Operators who receive SQL and need to ask better questions.

## Compatibility

- A text editor or Notion for the lessons
- PowerPoint, Keynote, or Google Slides for the PPTX
- A PDF reader for the worksheet

## Before you start

1. Read the README and this usage guide.
2. Open the main deliverable and replace every sample figure or sample sentence with your own.
3. Keep a copy of the original download before you edit it.
4. Check the licence before you share the edited file with anyone else.

## What you should see

- Four lessons with an exercise each
- Slides you can present to yourself or a colleague
- A worksheet of the exercises
