# Prompting at work worksheet

*This is a self-study pack: lessons, slides, and exercises. It is not an accredited qualification and it does not include a tutor.*

## Paste the source

Paste a paragraph and ask for a shorter version with no new facts.

## The check

Mark one invented detail and remove it.

## One job

Split a prompt that asked for three things.

## Sensitive data

Rewrite a prompt to remove a name it did not need.
