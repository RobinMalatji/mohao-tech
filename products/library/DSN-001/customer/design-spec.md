# Consultant discovery carousel

*SVG files you can upload. Not a native Canva template.*

A three-slide Instagram carousel for an independent consultant. The sample copy belongs to a fictional operations consultant, Naledi Mokoena, and walks a buyer from the problem to the session price.

## Files and sizes

| File | Pixels |
| --- | --- |
| slide-01-problem.svg | 1080 x 1080 |
| slide-02-session.svg | 1080 x 1080 |
| slide-03-price.svg | 1080 x 1080 |

## How to edit

1. Duplicate the three SVGs and replace Naledi's name.
2. Keep one idea on each slide: the mess, the session, the price.
3. Export PNG from your editor if a channel rejects SVG.

## Canva, Figma, and print

Create a design at the pixel size in the table, then upload the SVG. In Canva this is an upload, not a brand template from Canva's library. In Figma, place the SVG and edit the text layers. For print, add bleed in the editor. The SVG is the design area.

> Sample names and offers in these designs are fictional. Replace them before you publish. This package is not a native Canva file.
