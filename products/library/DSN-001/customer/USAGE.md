# How to use Consultant discovery carousel

*SVG design kit with HTML preview*

A three-slide Instagram carousel for an independent consultant. The sample copy belongs to a fictional operations consultant, Naledi Mokoena, and walks a buyer from the problem to the session price.

## Who it is for

Independent consultants who sell a fixed discovery session rather than an open-ended hourly pitch.

## Compatibility

- SVG files upload into Canva, Figma, Illustrator, and Inkscape
- Preview HTML opens in a current browser
- This package does not include a .canva file or a Canva link

## Before you start

1. Read the README and this usage guide.
2. Open the main deliverable and replace every sample figure or sample sentence with your own.
3. Keep a copy of the original download before you edit it.
4. Check the licence before you share the edited file with anyone else.

## What you should see

- Finished sample layouts you can edit
- Pixel sizes written on the preview page
- Colours and type set in the SVG, not in a screenshot
