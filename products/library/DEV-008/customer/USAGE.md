# How to use Safe download filename

*JavaScript source with node:test*

Returns a single file name or throws. It blocks slashes, backslashes, parent segments, null bytes, and Windows reserved names. Use it before you join a name onto a storage directory.

## Who it is for

Developers who want a small, readable module they can drop into a Node.js project and modify.

## Compatibility

- Node.js 20 or later
- Run npm test or node --test from this folder
