# Savings goal planner

*FIN-019 · version 1.0.0*

Work out the monthly amount for several goals from the target, the saved balance, and the months left.

Each goal has its own row. Monthly required is the gap divided by the months you enter. The workbook sums those monthly amounts so you can see whether payday can carry all of them.
