# How to use City trip itinerary

*Markdown and CSV import package*

An itinerary for two people. Booked items have a confirmation reference in the sample. Ideas do not, so you can tell what is real.

## Who it is for

Travellers who mix bookings and maybes and then forget which is which.

## Compatibility

- Notion import for Markdown and CSV
- Any editor that opens .md and .csv
- Not a Notion template URL

## Before you start

1. Read the README and this usage guide.
2. Open the main deliverable and replace every sample figure or sample sentence with your own.
3. Keep a copy of the original download before you edit it.
4. Check the licence before you share the edited file with anyone else.

## What you should see

- Pages you can import as Markdown
- A CSV database with example rows you replace
- Import steps that do not pretend this is a hosted Notion link
