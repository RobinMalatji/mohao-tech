# CSV parser and writer

*DEV-001 · version 1.0.0*

Parse and write CSV, including commas and quotes inside a field.

A small CSV parser for files you control. It handles quoted commas, escaped quotes, and CRLF line endings. It is not a full RFC 4180 implementation of every edge case, and the README in the module says so.
