# Side-hustle profit calculator

*FIN-016 · version 1.0.0*

Subtract materials, fees, and delivery from sales, then divide profit by hours.

The sample is a weekend baked-goods table. Profit is sales minus costs. The hourly figure uses the hours you type, including shopping and delivery, not only the stall time.
