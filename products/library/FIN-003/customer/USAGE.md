# How to use Emergency fund planner

*Excel workbook with PDF guide*

List the costs you would still pay if income stopped. The workbook multiplies that essential total by the number of months you choose, then estimates how many months the contribution will take.

## Who it is for

Households building a first cash reserve for rent, food, transport, and medical aid.

## Compatibility

- Microsoft Excel for Microsoft 365 or Excel 2021 and later
- Formulas also open in Google Sheets; confirm PMT, FV, and NPER after import
- PDF guide opens in any PDF reader
- DOCX guide opens in Microsoft Word or Google Docs

## Before you start

1. Read the README and this usage guide.
2. Open the main deliverable and replace every sample figure or sample sentence with your own.
3. Keep a copy of the original download before you edit it.
4. Check the licence before you share the edited file with anyone else.

## What you should see

- Separate essential costs from costs you could pause
- Set a month target without guessing a lump sum
- See how long the current contribution takes
