# Night-market poster

*DSN-009 · version 1.0.0*

A story-sized poster for a Thursday night market with the hours and the entrance.

A 1080 by 1920 story poster for the fictional Braamfontein Night Market. It states the date, the hours, and which gate to use. It does not list every stall.
