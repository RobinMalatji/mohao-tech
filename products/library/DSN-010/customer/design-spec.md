# Donation appeal card

*SVG files you can upload. Not a native Canva template.*

A donation card for a fictional library fund, Open Shelf. R350 buys a set of readers for one classroom. The card does not claim tax deductibility.

## Files and sizes

| File | Pixels |
| --- | --- |
| donation-card.svg | 1080 x 1080 |

## How to edit

1. Name the amount and the thing it buys.
2. Remove any tax claim unless your organisation has written advice that it is true.
3. Put the payment route in the caption, not crammed into the card.

## Canva, Figma, and print

Create a design at the pixel size in the table, then upload the SVG. In Canva this is an upload, not a brand template from Canva's library. In Figma, place the SVG and edit the text layers. For print, add bleed in the editor. The SVG is the design area.

> Sample names and offers in these designs are fictional. Replace them before you publish. This package is not a native Canva file.
