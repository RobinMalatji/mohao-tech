# Slug builder

*DEV-002 · version 1.0.0*

Turn a title into a URL slug without dropping the meaning of an ampersand.

Converts a product or article title into a lowercase slug. Ampersands become the word 'and'. Accented Latin letters are stripped of marks. The function does not call a network service.
