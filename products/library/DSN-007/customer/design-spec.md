# YouTube thumbnail pair

*SVG files you can upload. Not a native Canva template.*

Two 1280 by 720 thumbnails for a fictional channel, Sheet Club, about spreadsheets for operators. One promises a cash-flow layout. The other names a common mistake. No faces are included, so you are not stuck with a stock person.

## Files and sizes

| File | Pixels |
| --- | --- |
| thumbnail-howto.svg | 1280 x 720 |
| thumbnail-mistake.svg | 1280 x 720 |

## How to edit

1. Keep the title under four short lines.
2. Use the orange bar for the video that is a warning, and the light background for the how-to.
3. Test the type at 320 pixels wide.

## Canva, Figma, and print

Create a design at the pixel size in the table, then upload the SVG. In Canva this is an upload, not a brand template from Canva's library. In Figma, place the SVG and edit the text layers. For print, add bleed in the editor. The SVG is the design area.

> Sample names and offers in these designs are fictional. Replace them before you publish. This package is not a native Canva file.
