# How to use Tax season document checklist

*Excel workbook with PDF guide*

Tick what you have, what is missing, and what does not apply. The workbook counts each status. It does not calculate tax and it does not submit a return.

## Who it is for

Salaried people and sole proprietors preparing documents before they file, or before they meet a tax practitioner.

## Compatibility

- Microsoft Excel for Microsoft 365 or Excel 2021 and later
- Formulas also open in Google Sheets; confirm PMT, FV, and NPER after import
- PDF guide opens in any PDF reader
- DOCX guide opens in Microsoft Word or Google Docs

## Before you start

1. Read the README and this usage guide.
2. Open the main deliverable and replace every sample figure or sample sentence with your own.
3. Keep a copy of the original download before you edit it.
4. Check the licence before you share the edited file with anyone else.

## What you should see

- See how many documents are still missing
- Keep the source of each document next to the line
- Avoid starting a return with a half-finished folder
