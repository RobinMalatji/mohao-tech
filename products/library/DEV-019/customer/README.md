# Object list to CSV

*DEV-019 · version 1.0.0*

Write an array of objects to CSV using a column list you choose.

Columns you do not name are left out, so a customer export does not accidentally include a note field. Values are escaped with the same quoting rule as the CSV writer in this library's companion parser.
