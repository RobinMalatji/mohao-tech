# How to use Object list to CSV

*JavaScript source with node:test*

Columns you do not name are left out, so a customer export does not accidentally include a note field. Values are escaped with the same quoting rule as the CSV writer in this library's companion parser.

## Who it is for

Developers who want a small, readable module they can drop into a Node.js project and modify.

## Compatibility

- Node.js 20 or later
- Run npm test or node --test from this folder
