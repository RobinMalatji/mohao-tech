# Launch week checklist

*This is a working draft for a South African online shop. It is not legal advice. Have a lawyer read it before you publish it as your policy.*

## The week

Monday: the file opens on a second computer. Wednesday: the price matches in every currency you list. Friday: someone who did not build the page completes a test order in test mode, if your provider has one.

- File opens.
- Prices match.
- Test order.
- Support address works.
