# How to use Discount calculator

*JavaScript source with node:test*

Percent discounts use basis points so 1500 means 15.00 percent. Fixed discounts are integer cents in the same currency as the subtotal. The function does not look up a coupon code.

## Who it is for

Developers who want a small, readable module they can drop into a Node.js project and modify.

## Compatibility

- Node.js 20 or later
- Run npm test or node --test from this folder
