# How to use Reporting date buckets

*JavaScript source with node:test*

Uses UTC dates so a report does not change with the server's local zone. Week buckets start on Monday. It does not query a database.

## Who it is for

Developers who want a small, readable module they can drop into a Node.js project and modify.

## Compatibility

- Node.js 20 or later
- Run npm test or node --test from this folder

## Before you start
