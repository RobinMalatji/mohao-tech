# How to use Blog editing prompts

*Prompt library in Markdown and CSV*

Edit a draft for a specific reader without adding claims you did not write. Each prompt tells you what to paste, what to ask, and what to check before you use the answer.

## Who it is for

People who already have a draft and want it shorter and clearer.

## Compatibility

- Any chat model that accepts a pasted prompt
- A spreadsheet for the CSV
- No model subscription is included

## Before you start

1. Read the README and this usage guide.
2. Open the main deliverable and replace every sample figure or sample sentence with your own.
3. Keep a copy of the original download before you edit it.
4. Check the licence before you share the edited file with anyone else.

## What you should see

- A full prompt, not a one-line topic
- A check so you do not ship an invented fact
- The same prompts in Markdown and CSV
