# Blog editing prompts

*These prompts draft text for you to edit. They do not check facts, quotes, or the law. Remove anything the model invented before you send it.*

## Reader test

Use when: Before a line edit.

Read this draft as the reader I name. List the sentences that assume knowledge the reader does not have. Do not rewrite yet.

> Check: The list quotes the draft.

## Cut a third

Use when: When the draft is too long.

Cut this draft by about a third. Do not add examples, statistics, or quotations. Keep the original claims.

> Check: The shorter draft has no new facts.

## Headline options

Use when: When you need titles.

Write eight headlines. Each must be true to the draft. Mark any headline that would overclaim.

> Check: You reject the overclaims.

## Specifics pass

Use when: When the draft is vague.

Replace vague nouns with the specific ones already in the draft. If a specific is missing, insert [missing specific] rather than inventing one.

> Check: No invented numbers.

## Opening

Use when: When the first paragraph is a warm-up.

Propose two openings that start at the first concrete point in the draft. Do not add a story.

> Check: The opening is already in the draft.

## Last check

Use when: Before you publish.

List factual claims in the draft that would need a source. Do not supply sources from memory.

> Check: You verify each one yourself.
